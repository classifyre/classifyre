Queries can now be shared as **shared datasets**: on the SQL page, *Share as dataset* turns a query over one or more tables into a governed dataset (`shared.<domain>.<name>`) that other groups read — on the SQL page, Data tabs, exports, SQL connections and AI agents — without any access to the tables behind it. The tables are read with the access of the dataset's owning group, checked on every read; their masks, row filters and column classification carry into the dataset and can be made stricter, never looser. Owners of those tables are told when their table is shared and can block a dataset. Each dataset has its own owner, Promoted and Certified badges, versions, column lineage, quality checks, access requests and activity, and all of them are listed on the new *Shared datasets* page. Sharing needs the new *Dataset publisher* role, or owning or stewarding every table a dataset reads. Over SQL connections a dataset reads only tables that are themselves open to SQL connections, and such a table cannot be closed while a draft or active dataset open to connections reads it: deprecate or retire the dataset first.
