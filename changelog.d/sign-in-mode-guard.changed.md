Turning sign-in off no longer opens every tenant's workspaces to anyone: without sign-in Classifyre shows only the workspaces made without it, and a tenant's workspaces stay hidden until sign-in is back on. Turning sign-in on no longer moves existing workspaces into the first tenant either; an operator moves them with `node dist/src/admin.js workspaces move` in an API pod, which also moves a workspace out of a tenant again. Each move is in the tenant's activity.
