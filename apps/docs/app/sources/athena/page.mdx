On AWS, the Glue Data Catalog is the list of what's in the lake, and Athena is
the way to read it. This source lists databases and tables from Glue and reads
rows with Athena SQL, so each format is read by its own reader.

## What you need to connect

The **region** and an **S3 location for query results** (Athena writes every
query's result there). Give an access key pair, or leave it empty to use the
environment's ambient AWS credentials. The identity needs Glue read access,
Athena query access, read access to the tables' data, and write access to the
results location.

## What Classifyre reads

Every Glue database and its tables and views, or only the ones you list. Each
table reports its format from Glue: `iceberg`, `delta`, `hudi`, `external` for
plain files, or `view`, plus its storage location.

## Worth knowing

- **Athena bills by bytes scanned**, and a row limit doesn't reduce what a scan
  of an unpartitioned table reads. Every page of rows is one query, so the page
  size is also the cost knob, and RANDOM sampling reads the whole table once per
  run.
- **Another data catalog** registered in Athena can be named in place of the
  default `AwsDataCatalog`.
