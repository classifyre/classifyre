BigQuery is Google Cloud's warehouse and, through BigLake, its lakehouse too.
This source scans the datasets of one project: native tables, BigLake tables,
BigQuery tables for Apache Iceberg, external tables over Delta or Iceberg, and
views.

## What you need to connect

The **project id**, and a service-account key in JSON, or nothing at all to use
the environment's ambient Google credentials (workload identity). The account
needs BigQuery Data Viewer on the datasets, and BigQuery Job User on the
project that is billed for queries.

## What Classifyre reads

Every dataset and its tables and views, or only the ones you list. Each table
reports its format: `native`, `iceberg`, `delta`, `external` or `view`, plus its
storage location for external tables.

## Worth knowing

- **Most reads cost nothing.** ALL and AUTOMATIC page through tables with the
  table-listing API rather than a query, so no bytes are billed. RANDOM and
  LATEST need an `ORDER BY` and run a query; set a maximum bytes billed to cap
  it.
- **A separate billing project** can be named when the data and the bill live
  in different projects.
