Meilisearch powers the search box in front of an application — which means the
documents it holds are a copy of whatever that application shows users, indexed
for speed and rarely reviewed for content.

## What you need to connect

The **instance URL**, and an **API key** if the instance has one. Meilisearch has
no username-and-password authentication — it's a key or nothing. A search-scoped
key is enough.
